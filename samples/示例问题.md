# 示例问题与预期结果

示例文件：`samples/示例销售数据.xlsx`，包含 3 个工作表：

- **销售明细**：1,102 行 × 9 列，日期范围 2024-10-01 至 2026-09-28，含少量缺失值和 4 行完全重复数据。
- **区域目标**：6 行 × 4 列，表头上方有 2 行说明文字，用于验证表头自动识别。
- **字段说明**：9 行 × 3 列，用于验证多工作表切换。

> 以下数值基于当前示例文件，若修改或重新生成示例数据，结果会同步变化。

## 推荐问题

1. **近12个月销售额趋势如何？**
   - 预期结论：12 个月合计 **1,692.12 万元**，整体平稳；峰值 **2025-11（403.63 万元）**，谷值 2026-04（68.60 万元）。
   - 图表：折线图，12 个月度数据点。

2. **找出销售额异常波动的月份。**
   - 预期结论：识别到 **2 个异常点：2025-11（403.63 万元，去趋势残差 Z +13.13）** 与 **2025-03（190.12 万元）**。
   - 说明：异常判定用“原始序列 + 线性去趋势残差”双重口径；单用原始序列 MAD 只会报出 2025-11，次级峰值 2025-03 会被大额尖峰抬高的离散度“洗白”。
   - 图表：折线图 + 异常点标记。

3. **对比各区域的利润并排名。**
   - 预期结论：**华东** 利润最高，为 **253.33 万元**，共 6 个区域参与对比。
   - 图表：横向条形图，按利润降序排列。

4. **近6个月各区域的销售额对比。**
   - 预期结论：时间窗口被限制为 2026-04 至 2026-09；**华东** 最高，为 **208.82 万元**，6 个区域合计 718.32 万元。
   - 用于验证“时间范围”会同时作用于趋势/对比查询。

5. **对比各产品类别的销售额。**
   - 预期结论：**咨询服务** 最高，为 **1,048.21 万元**，共 4 个类别。
   - 图表：分类条形图，可导出 PNG 和明细 CSV。

6. **数据整体情况如何？**
   - 预期结论：返回记录规模、字段数、主要分类及分组汇总，而不是生成虚构结论。

7. **区域目标工作表中，对比各区域的已达成情况。**
   - 先切换到“区域目标”工作表，再提问。
   - 用于验证中文表头、数值字段和多工作表切换。

8. **各销售渠道的销售额占比分布如何？**
   - 预期结论：按销售渠道汇总销售额并计算占比。
   - 注意“销售渠道”有 3 行缺失值，结果会提示缺失情况。

## 追问示例

在同一文件、同一工作表内连续提问，系统会自动继承上一轮口径：

1. 先问：**对比各区域的利润并排名。**
   - 预期：华东利润最高，253.33 万元，6 个区域对比。
2. 接着问：**那销售额呢？**
   - 预期：保留“区域”分组和对比类型，指标换成销售额；结果标记“追问”，华东销售额最高，896.66 万元。
3. 再问：**只看华东。**
   - 预期：沿用销售额与区域口径，并追加 `区域 = 华东` 筛选。
4. 再问：**再按月看看。**
   - 预期：沿用指标与筛选，切换为月度时间粒度。

其他可尝试的追问：

- 按季度汇总销售额趋势。
- 对比各产品名称的销量并排名。
- 华东区域的利润趋势如何？
- 找出利润异常偏低的月份。

## 字段备注示例

1. 在数据概览中点击“利润”字段 chip，填写备注：**毛利口径，不含运费**。
2. 再问：**找出毛利的异常波动月份。**
3. 预期：规则规划通过备注别名命中“利润”字段，结果卡“分析口径与方法”中显示该字段备注。
4. 将该备注留空保存，即可删除备注。

## 收藏与报告示例

- 在任一结果右上角点击星标 → 左侧“我的收藏”出现该分析；点“面板”可查看、重跑、重命名或删除。
- 点击结果工具条的文档图标 → 下载 Markdown 报告。
- 点击打印机图标 → 新窗口打开打印版 HTML，按 `Ctrl + P` 可另存为 PDF。

## 验收关注点

- 一句话结论、指标卡、图表、数据事实、推测与建议、明细、分析口径是否完整。
- 结论中的数字是否都能在“数据事实”或明细中核对。
- 切换工作表后，字段与推荐问题是否同步变化；换表后追问上下文是否已清空。
- 字段备注保存后 chip 是否出现圆点，问别名能否选中对应字段。
- 追问结果是否带“追问”标记，指标/分组/筛选是否符合预期。
- 收藏是否可新增、打开、重跑、重命名、删除；重跑追问收藏是否保持原口径。
- Markdown 报告是否可下载，打印版 HTML 是否能正常打开并打印。
- 刷新页面后，左侧文件、收藏与历史分析是否仍在。
- 未配置模型时应显示“规则模式”，配置后应显示模型名称。
- 图表下载 PNG、明细导出 CSV、结论复制是否可用。
